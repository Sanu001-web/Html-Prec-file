# 🌐 Web Development Projects

A collection of frontend web development projects built while learning and practicing HTML, CSS, and UI design concepts — ranging from real-world clones to layout experiments.

---

Projects

| Project | Description |
|---|---|
| **Amazon Clone** | A static clone of Amazon's homepage with a fully styled navbar, hero section, product cards, and footer with copyright |
| **YouTube Clone** | YouTube-inspired UI with a sidebar, search bar with tooltips, and responsive layout |
| **Portfolio** | Personal portfolio site featuring an about section, services, and admin image integration |
| **Food Company** | A landing page for a food brand with modern styling and layout |
| **Image Gallery** | A clean, responsive image gallery with custom stylesheet |
| **Prectice (CSS Tabs)** | Vertical tab card component built with pure CSS |
| **FlexxBox** | Flexbox layout experiments with a styled navigation bar |
| **Nestedflex** | Nested Flexbox practice exercises (13f, 13g) |
| **Position Practice** | CSS positioning exercises including a product display container with button |
| **Abstract** | Responsive Help Center Web Page with Navigation, Hero Boxes, and Footer |

- Image galleries & media styling

Getting Started

Clone the repo and open any `.html` file directly in your browser — no build tools or dependencies required.
```bash
git clone https://github.com/Sanu001-web/Html-Prec-file/edit/main/README.md
cd README.md
```

These projects are part of my frontend learning journey. Each folder contains its own `.html` and `.css` file pair. Feel free to explore, fork, or use as reference!
